FastReader помогает читать быстрее: текст подаётся по одному слову в центр окна, а темп
задаётся слайдером. Это реализация техники **RSVP (Rapid Serial Visual Presentation)** —
глаз не тратит время на движение по строке и на возвраты назад, поэтому читать получается
быстрее. Удобно использовать как разминку перед чтением или для больших объёмов текста.

> **English:** FastReader is a desktop speed-reading trainer built with Python and
> [Flet](https://flet.dev). It flashes a text file word by word at an adjustable interval
> (the RSVP technique). Pick a `.txt` file, press **Старт** and tune the interval slider.
> The interface is in Russian.

## Возможности

- **Показ по одному слову** — текст разбивается на слова и выводится по одному в центр окна.
- **Настраиваемая скорость** — слайдер от 100 до 1100 мс на слово с шагом 100 мс.
- **Автоопределение кодировки** — файл читается через [`chardet`](https://pypi.org/project/chardet/),
  поэтому открываются и UTF-8, и Windows-1251.
- **Пауза и продолжение** — показ останавливается на текущем слове и продолжается с него же.
- **Сброс долгим нажатием** — кнопка возвращает показ в начало.
- **Тёмная тема** с красным акцентом, окно фиксированного размера 600×500.

## Требования

- Python 3.9+
- [Flet](https://flet.dev) `0.22.x`

## Установка

```bash
git clone https://github.com/B-es/FastReader.git
cd FastReader

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

### О версии Flet

Интерфейс построен на API Flet `0.22`: `ft.icons`, свойства `page.window_*`. В версиях 0.23
и выше эти имена изменились, поэтому зависимость закреплена в `requirements.txt` — ставьте
Flet оттуда, а не отдельным `pip install flet`.

## Как пользоваться

1. Нажмите **«Выбрать файл»** и выберите текстовый файл — кодировка определится автоматически.
2. Задайте интервал слайдером: 100 мс — очень быстро, 1100 мс — спокойный темп.
3. Нажмите **«Старт»**, чтобы начать показ.

| Действие | Что происходит |
| --- | --- |
| Клик по «Старт» | начинается показ с первого слова |
| Клик по «Стоп» | показ останавливается на текущем слове |
| «Старт» после остановки | показ продолжается с того же слова |
| Долгое нажатие на кнопку | показ возвращается к началу |

## Как это устроено

Приложение живёт в `main.py` (~200 строк) и состоит из трёх виджетов — наследников Flet:

- **`StartStopButton`** (`ft.ElevatedButton`) — инкапсулирует переключение «Старт/Стоп»: сам
  меняет текст и иконку, хранит текущее состояние и вызывает нужный колбэк. Долгое нажатие
  (`on_long_press`) обрабатывается отдельно от обычного клика.
- **`StartStopWidget`** (`ft.Column`) — показывает слова. Показ идёт в отдельном
  `threading.Thread`, пауза реализована через `threading.Event`, остановка — флагом `isStop_t`
  и `Thread.join()`. Виджет владеет списком слов, слайдером интервала и кнопкой.
- **`OpenFileWidget`** (`ft.Column`) — `ft.FilePicker`, определение кодировки через
  `chardet.universaldetector.UniversalDetector` и разбиение прочитанного текста на слова.

Точка входа — `ft.app(main, assets_dir='assets')`; оттуда Flet подхватывает
`assets/icon.png` (иконка приложения) и `assets/favicon.png` (favicon для web-сборки).
